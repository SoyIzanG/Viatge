*Creació de documents bàsics o complexos en Google, vinculat a Google Drive.*

**Propòsit:** Ens permet crear, editar i compartir documents de Google, en una interfície bastant senzilla al navegador.  
**Target:** Facilita ajuda als estudiants, equips de treball, treballadors, empreses, per poder-ne redactar i compatir el document.  

**Google Drive**
*Emmagatzematge gratuït amb un límit, en l'opció de pagar per tenir més emmagatzematge al núvol.*

*Calendari personal, el qual et permet gestionar qualsevol esdeveniment.*
